## 📈 WHAT THE PROJECT MODELS

### **6 User Engagement States**
```
Visitor → Browsing → Watching → Binge Watching
   ↓                                    ↓
   └────────────────► Subscriber ←─────┘
                         ↓
                       Churn (Absorbing State)
```

### **Key Metrics It Computes**
- ✅ Conversion Rate (Visitor → Subscriber %)
- ✅ Churn Rate (% users leaving)
- ✅ Retention Rate (% staying active)
- ✅ Active User Count
- ✅ Final State Distribution
- ✅ Steady-State Equilibrium
- ✅ Ergodicity Properties
